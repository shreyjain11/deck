# RCC — Remote Claude Code orchestrator (instructions for THIS session)

You are the **orchestrator**. This folder controls other Claude Code sessions
running on this machine inside **tmux**. You discover them, send prompts, read
output, and run autonomous goal loops that a cheap evaluator + Fable reviews
drive to genuine completion — no human checkpoints.

## Prerequisite
`tmux` MUST be installed (RCC talks to workers through it):
`brew install tmux` (macOS) / `sudo apt install tmux`. Confirm with `tmux -V`.
Then run `scripts/rcc-verify-models` once to confirm the model strings resolve.

## Current state
Live registry: **[SESSIONS.md](SESSIONS.md)** (regenerated by `rcc-list`).
Per-goal detail: `goals/<session>.md`. Reviews: `reviews/`. Logs: `logs/`.

## Scripts (all in `scripts/`, all executable, all take `--help`)
| Script | Does |
|--------|------|
| `rcc-list` | List tmux sessions, flag which run Claude, refresh SESSIONS.md |
| `rcc-send <s> "<prompt>"` | Type a prompt into session `s` (+Enter); waits out a busy target, else queues with a warning |
| `rcc-read <s> [lines]` | Print last `[lines]` (default 80) of `s`'s pane |
| `rcc-goal <s> "<goal>" "<criteria>" ["<milestones>"]` | Create `goals/<s>.md`, launch the loop (nohup) |
| `rcc-loop <s>` | The autonomous loop (usually launched by `rcc-goal`) |
| `rcc-status` | Dashboard: status, iterations, last verdict, loop liveness, spend |
| `rcc-stop <s> [reason]` / `rcc-stop --all` | Halt loop(s), write a final summary |
| `rcc-verify-models` | Confirm the routed models resolve (spec step 5) |
| `rcc-selftest` | Offline test of all logic using mock tmux + claude |
| `rcc-acceptance` | Live end-to-end checklist (real tmux + claude), auto-cleans |

## Model routing (cost)
- **Worker** sessions write code on **Sonnet** (`RCC_MODEL_WORKER=sonnet`).
  Start them yourself: `claude --model sonnet` (or `/model` inside).
- **Evaluator** runs EVERY iteration on **Haiku** (`RCC_MODEL_EVAL=haiku`),
  headless `claude -p`, strict-JSON only — cheapest possible.
- **Reviews** (milestone + final ONLY) run on **Fable 5**
  (`RCC_MODEL_REVIEW=claude-fable-5`). The `fable` alias is unverified on this
  box, so the default is the full id, which is guaranteed to resolve.
Override any of these in `rcc.conf` (see `rcc.conf.example`).

## Token rules
- Fable NEVER sees raw transcripts — only: the goal file + a `git diff`
  (diff only, `--stat` + first 400 lines) + a ≤10-line Haiku progress summary.
- The evaluator sees only the last `RCC_READ_LINES` (80) pane lines + goal file.
- Every evaluator/review prompt demands terse output. Logs are one line/iter,
  never transcripts.
- Tell workers (via injected prompts) to run `/compact` when context gets heavy.

## Loop guards (defaults; override via env or rcc.conf)
- `RCC_MAX_ITERS=50` — hard cap on iterations.
- `RCC_MAX_FAILS=5` — consecutive evaluator failures ⇒ mark `failed`, stop.
- `RCC_STALL_READS=3` — identical reads ⇒ nudge once, then count as a fail.
- `RCC_SLEEP=45` — seconds between iterations (30–60 sensible).
- `RCC_CONF_HIGH=0.8` — evaluator confidence gate before a "done" claim.
- **Done is never the worker's call**: only evaluator(goal_done+confident) AND
  a Fable final review PASS mark a goal `done`.

## Loop algorithm (per iteration)
read pane → Haiku evaluator returns
`{milestone_done,goal_done,next_instruction,confidence}` →
  - `goal_done` & confident → **final Fable review**; PASS ⇒ done, FAIL ⇒ feed
    feedback to worker, continue.
  - `milestone_done` → **milestone Fable review**; PASS ⇒ check the box, advance;
    FAIL ⇒ feed feedback, continue.
  - else → send `next_instruction` to the worker, sleep.
Every iteration appends one terse line to `logs/<s>.log` and one row to the
goal file's iteration table. Failures also write `STATUS: failed` to the goal.

## Conventions
- Bash only, macOS/BSD-safe, targets bash 3.2. Never `--dangerously-skip-permissions`.
- Loops run detached (nohup) so they survive disconnects; PID in `.state/<s>.pid`.
- Add `scripts/` to PATH for convenience: `export PATH="$HOME/rcc/scripts:$PATH"`.
